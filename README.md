# طالب العراق — Telegram Bot

## المزايا الحالية
- تسجيل المستخدمين تلقائياً.
- اختيار المرحلة والفرع الدراسي.
- تصفح الملازم والملفات حسب المرحلة والفرع والمادة.
- اختبارات اختيار من متعدد وتصحيح فوري.
- لوحة إدارة لإضافة الملفات والأسئلة وإرسال الإعلانات.
- إحصائيات أولية.

## التشغيل محلياً
1. ثبّت Python 3.10 أو أحدث.
2. أنشئ بيئة افتراضية وثبّت المتطلبات:
   `pip install -r requirements.txt`
3. انسخ `.env.example` إلى `.env`، ثم عيّن المتغيرات في بيئتك. لا ترفع ملف `.env` إلى Git.
4. شغّل: `python bot.py`

ملاحظة: الكود يقرأ المتغيرات من بيئة التشغيل. للتشغيل المحلي يمكنك تثبيت `python-dotenv` وإضافة `load_dotenv()` أو تعيين المتغيرات يدوياً.

## النشر على Render
1. ارفع مجلد المشروع إلى مستودع GitHub خاص.
2. أنشئ Background Worker جديداً في Render واربط المستودع، أو استخدم `render.yaml`.
3. أضف `BOT_TOKEN` من إعدادات Environment في Render.
4. تأكد أن `ADMIN_IDS` يساوي `5865382078`.
5. انشر الخدمة وراجع السجلات للتأكد من ظهور `Student IQ bot is running`.

## أوامر الإدارة
- `/admin` عرض لوحة الإدارة.
- `/add_material` إضافة ملف. أرسل البيانات: `المرحلة | الفرع | المادة | عنوان الملف` ثم أرسل الملف.
- `/add_question` إضافة سؤال بصيغة: `المرحلة | الفرع | المادة | السؤال | أ | ب | ج | د | الإجابة`
  حيث الإجابة حرف واحد: `a` أو `b` أو `c` أو `d`.
- `/broadcast` إرسال إعلان نصي للمستخدمين الذين بدأوا البوت.
- `/stats` عرض الإحصائيات.
- `/cancel` إلغاء العملية الحالية.

## تنبيهات مهمة
- لا ترسل توكن BotFather لأي شخص ولا تضعه داخل ملفات الكود.
- هذا إصدار أولي قابل للتشغيل، ويحتاج اختباراً فعلياً قبل إطلاقه للطلاب.
- قاعدة SQLite مناسبة للبداية الصغيرة. للنمو والاستضافة طويلة الأمد يفضّل استخدام PostgreSQL وتخزين دائم.
- يجب احترام حقوق نشر الكتب والملازم، وعدم نشر محتوى لا تملك حق توزيعه.
